LCode Technologies

Location: Chennai, India

Project: Cross-platform endpoint monitoring and security analytics platform

Overview

I worked on an endpoint-monitoring solution for Windows and macOS systems to collect antivirus-related telemetry and relay it to a centralized backend. The goal was to keep endpoint health information visible and actionable without depending on a single platform-specific implementation.

Work Delivered

  • Developed endpoint telemetry collection using TypeScript and Node.js.
  • Collected antivirus product details, version data, scan information, and license-expiry telemetry.
  • Separated telemetry collection from Windows service lifecycle management.
  • Implemented a C# Windows Service with tray-based control for local operations.
  • Used Named Pipes for communication between the Windows service and the endpoint process.
  • Built ingestion workflows using Express.js, PostgreSQL, and Prisma.
  • Implemented checks for overdue scans, license expiry, and missing endpoint heartbeats.
  • Built a native Swift launchd daemon for macOS-based endpoint behavior.

Engineering Challenges

  • Cross-platform architecture: Windows and macOS use fundamentally different service and lifecycle models.
  • Privilege separation: separating privileged background execution from user-session interaction.
  • Inter-process communication: using Named Pipes to create a reliable service-to-process channel.
  • Platform-specific diagnostics: understanding permissions, launchd behavior, and background-process management on macOS.
  • Telemetry reliability: ensuring endpoint data was collected and ingested consistently under real operating-system conditions.

Learning Outcomes

  • Windows service architecture and process lifecycle.
  • IPC and Named Pipes.
  • macOS launchd and Swift integration.
  • Cross-platform systems engineering.
  • Backend telemetry ingestion and operational monitoring.
  • Debugging privileged background processes and service behavior.

Developer / Full-Stack Engineer

VelaCafe

2025 – Present

Live Product: vela-cafe.vercel.app

Verified Impact: 4,000+ signups and approximately ₹6,000 revenue

Overview

VelaCafe is a full-stack café ordering platform designed to digitize customer ordering and simplify café operations. It brings together customer interactions, order tracking, inventory management, and admin workflows in a single deployed product.

Work Delivered

  • Designed and developed the complete full-stack application.
  • Implemented customer ordering workflows and menu handling.
  • Applied atomic conditional updates to reserve stock during checkout.
  • Used MongoDB transactions to reduce overselling under concurrent orders.
  • Implemented time-limited stock reservations and scheduled recovery logic.
  • Unified payment verification and webhook handling through an idempotent order-finalization flow.
  • Used server-side payment snapshots and database uniqueness constraints to handle duplicate callback attempts.
  • Implemented JWT-authenticated Socket.IO rooms for real-time order updates.
  • Authorized customers before allowing access to their order channels.

Engineering Challenges

  • Inventory concurrency: multiple customers can attempt to buy the same item simultaneously, so stock checks and decrements had to be atomic.
  • Reservation expiry: database TTL cleanup alone is insufficient when inventory must be restored as soon as a reservation times out.
  • Payment idempotency: both payment verification and webhooks can attempt to finalize the same order, so the backend had to tolerate duplicate callbacks safely.
  • Real-time authorization: order updates needed to be visible only to the correct customer and admin contexts.

Learning Outcomes

  • Building and maintaining a real-world deployed application.
  • Database transactions and concurrency control.
  • Atomic database operations and stock consistency.
  • Webhook-based payment workflow design and idempotency.
  • Real-time communication and authenticated event channels.
  • Translating business requirements into product-aware engineering decisions.
Technologies:
React Node.js Express.js MongoDB Socket.IO JWT Razorpay Cloudinary Nodemailer
